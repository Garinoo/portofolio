GARINO WIJAYA — PORTFOLIO V2

A responsive editorial-style personal portfolio built with HTML, CSS, and JavaScript.

PREVIEW
Open index.html in your browser. An internet connection is required for the Google Fonts.

CUSTOMIZE BEFORE PUBLISHING
1. Replace your.email@example.com with your active email in index.html.
2. Add your LinkedIn URL and other professional contact links.
3. Check each project description and technology list against your actual contribution.
4. Add more project case studies, screenshots, and measurable outcomes as they become available.

PUBLISH
Upload this folder to Cloudflare Pages using Direct Upload, or push it to GitHub and connect the repository to Cloudflare Pages.
